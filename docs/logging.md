# Logging policy

Production logs should contain operational metadata, not customer content.

Safe structured fields include `trace_id`, component, dependency, stage, outcome, bounded rule IDs, latency and HTTP status. Do not log raw prompts, completions, Authorization headers, API keys, privacy mappings, cache contents, or arbitrary error payloads that may contain customer data.

Configuration debug/display output must mask Redis URL credentials and all configured API keys/tokens. The authoritative correlation identifier is generated by AI Cost Firewall and returned as `X-VCAL-Trace-ID`; client-provided values must not replace it.
